ARGUS // SEE WHAT MOVES

◈ THE PIPELINE

We pull raw FITS images from the NASA/IPAC IRSA SPHEREx archive, match wavelengths (within 0.2µm) to avoid false brightness changes, align the frames, and use difference imaging to isolate moving objects.

◈ HOW TO READ

The green ring indicates the catalog expected position. A dot that shifts outside the ring across the timeline is a candidate moving object.

◈ AI DISCLOSURE

Backend pipeline, 3D UI, and image processing co-developed with Antigravity and Claude AI.
